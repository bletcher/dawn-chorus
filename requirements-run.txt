# Deliberately does NOT include TensorFlow. BirdNET's .tflite runs under LiteRT
# (`ai-edge-litert`), which is ~150 MB against TensorFlow's ~2 GB and produces
# byte-identical results -- desktop/birdnet_lite.py was validated against
# BirdNET-Analyzer at 480/480 detections, max delta 0.0002.
#
#     py -3.12 -m venv .venv
#     .venv\Scripts\python -m pip install -r requirements-run.txt
#     .venv\Scripts\python -m pip install -e .
#
# birdnet-analyzer is NOT required. Install it only if you want --engine analyzer
# (the reference implementation) for cross-checking; it pulls in TensorFlow.
